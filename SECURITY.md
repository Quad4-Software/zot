# Security Policy

This repository is Quad4's fork of [zot](https://github.com/project-zot/zot).

## Supported Versions

Only the latest tagged release is supported.

## Reporting a Vulnerability

When a vulnerability is found, please *DO NOT* file a public issue. Instead,
file a [private security advisory](https://github.com/Quad4-Software/zot/security/advisories)
against this repository.

If the vulnerability is in unmodified upstream code, consider also reporting it
to the upstream project at
[project-zot/zot](https://github.com/project-zot/zot/security/advisories).
